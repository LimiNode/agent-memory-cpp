# Per-dimension INT8 K1 coarse control (2026-09-14)

## Question

Can the mean-of-K16 coarse layer be stored as a compact per-dimension INT8
sidecar without changing the downstream native K16/R4/THQ quality frontier?

## Setup

- the same frozen DE-1M, 152 queries, three semantic R4 seeds, and FP32 quality
  receipt as the integrated native K1/K16 experiment;
- each 384-dimensional mean-coarse store is quantized independently per
  dimension with symmetric signed INT8 codes and one FP32 scale per dimension;
- native coarse scoring uses the INT8 code and scale directly, then performs the
  same INT8 K16 refinement, three-seed posting fusion, THQ interval-squared
  top-256, and exact top-10 rerank;
- the matched comparison is the FP32 integrated raw output, joined row by row;
- quality rows use A=8192 and A=16384 per seed and budgets 5k/10k/20k/50k;
- teacher IDs remain evaluation-only.

The three coarse code stores total 75,009,792 bytes plus 4,608 bytes of scale
metadata, versus 300,039,168 bytes for the three FP32 stores (a 4x payload
reduction; the exact FP32 bytes remain bound by the source manifest).

| 8192 | 5k | .994079 | .992763 | −.001316 |
| 8192 | 10k | .994079 | .993421 | −.000658 |
| 8192 | 20k | .994079 | .993421 | −.000658 |
| 8192 | 50k | .994737 | .994079 | −.000658 |
| 16384 | 5k | .997368 | .997368 | 0.000000 |
| 16384 | 10k | .997368 | .997368 | 0.000000 |
| 16384 | 20k | .997368 | .997368 | 0.000000 |
| 16384 | 50k | .997368 | .997368 | 0.000000 |

THQ top-256 and exact top-10 teacher recall are identical to the INT8
candidate recall in every row, so this control introduces no additional
downstream loss. Native arithmetic timings are directional: per seed, coarse
scan p50 is about 35.7–36.0 ms, K16 refinement p50 is about 45 ms at A=8192
and 95 ms at A=16384. These are not end-to-end or MDBX timings.

## Interpretation

Per-dimension INT8 is a viable compact coarse representation. A=16384 is
bit-for-bit frontier-equivalent to the FP32 control on this frozen workload;
A=8192 has a small, measurable loss at the smallest budget. The quantized
sidecar therefore reduces representation footprint without invalidating the
K16/R4/THQ cascade, but it does not by itself solve full coarse-scan cost or
provide physical page behavior.

The next engineering gate is a SIMD/batched scorer and page-matched layout
measurement for this compact sidecar, followed by an MDBX-oriented read
control. No production activation is licensed by this experiment alone.
