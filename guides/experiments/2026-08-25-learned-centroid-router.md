# Routing-aware learned centroid router

This calibration-only follow-up is authorized because strict and explicitly
overcomplete unsupervised ITQ codes remained materially below the predeclared
selective centroid-coverage gate. It trains a shared binary projection only on
the separate Spanish train-query bundle and frozen float semantic-IVF
centroids. The teacher positives are each query's exact float top-16 centroids;
hard negatives are current binary top-64 centroids outside that teacher set.

The objective is a routing margin, not vector reconstruction: it increases the
binary similarity of teacher-positive centroids over binary-ranked distractors.
Spanish dev queries/qrels remain unavailable during fitting and selection.
